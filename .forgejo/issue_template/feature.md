## What's the use case?

Who wants this and why? "I would like X because Y." Not "the project should support X."

## Proposed behavior

## Alternatives considered

## Out-of-scope check

Read CONTRIBUTING.md "What's out of scope" — does this fall in that
list? If yes, explain why it should still be considered.

## Hardware implications (if applicable)

Does this need a specific programmer / VTX model / firmware version?
List them so the maintainer knows what's required to test.
